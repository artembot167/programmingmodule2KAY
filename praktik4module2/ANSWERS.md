# Відповіді на питання (практична робота 4)

**Номер мого варіанта: 7**

**1. Які коди стану й винятки обробляє моя функція і чому саме так?**

Моя функція перевіряє HTTP-код відповіді сервера. Якщо сервер повертає код 200, програма продовжує роботу та отримує дані. Якщо код інший, виникає помилка `RuntimeError`, щоб програма не обробляла неправильну відповідь. Також перевіряються параметри `page_size` і `max_pages`. Якщо вони неправильні, виникає `ValueError`.

**2. Що б сталося з моєю програмою без `timeout` і без перевірки коду стану?**

Без `timeout` програма могла б дуже довго чекати відповіді від сервера. Якщо сервер не працює або має проблеми, виконання могло б зависнути. Без перевірки HTTP-коду програма могла б спробувати обробити відповідь із помилкою як звичайні дані.

**3. Чим мій розв'язок відрізнявся б, якби API було справжнім і недоступним протягом хвилини?**

Якби справжній API не відповідав протягом хвилини, моя програма не чекала б увесь цей час, оскільки в запиті встановлено `timeout=5`. Після перевищення часу очікування бібліотека `requests` викликала б виняток. У реальному проєкті я б додав повторні спроби запиту з паузами між ними, щоб програма могла відновити роботу після тимчасової проблеми із сервером.
