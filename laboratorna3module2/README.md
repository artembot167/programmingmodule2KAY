# Стартовий проєкт: лабораторна робота 3

1. Відкрийте проєкт у GitHub Codespaces (Code → Codespaces → Create codespace) або локально: `python3 -m venv .venv`, `source .venv/bin/activate`, `pip install -r requirements.txt`. Права адміністратора не потрібні. Інтернет для перевірки не потрібен: тести самі запускають учбові сайти на `127.0.0.1`.
2. Визначте свою задачу й набір за номером варіанта: задача = `(номер - 1) // 3 + 1`, набір (сайт) = `(номер - 1) % 3 + 1`. Реалізуйте функцію у файлі `variants/lab_NN.py` за карткою варіанта.
3. Запускайте відкриті тести своєї задачі й свого набору: `pytest tests/test_lab_NN.py -k S2` (замініть `S2` на свій набір: `S1`, `S2` або `S3`).
4. Подивитися сайт у браузері: `python tests/sites.py S1` (так само S2, S3), зупинка Ctrl+C.
5. Змінюйте лише свій файл у `variants/` (і за бажанням додавайте `tests/test_my.py`).
6. Здача: `lab_NN.py`, `ANSWERS.md` і знімок екрана з зеленими тестами свого набору.
